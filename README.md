# Kasr Al-Ainy Exams

Practice examination platform for Kasr Al Ainy Faculty of Medicine, Cairo University. Module 101 is live; more modules are added incrementally without restructuring.

- **Run locally:** `cd app && npm start` → http://localhost:3000
- **Run tests:** `cd app && npm test`
- **Deploy:** see `app/SETUP_FIREBASE.md` (Firebase Hosting + Firestore, already configured for the live project)
- **Full history of what was built and why:** `IMPLEMENTATION_REPORT.md`
- **If you're Claude (or another AI) picking this up in a new session:** read `CLAUDE.md` first.

Live site: https://kasr-aliny-exams.web.app/
